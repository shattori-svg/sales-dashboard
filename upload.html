Data Upload

Upload Excel or CSV. CSV format: Business_Date, Store_Id, Department_Code, Start_Time, End_Time, Net_Sales, Gross_Sales, Quantity_Sold, Receipt_Count (00=total, 01–06=dept). Start_Time/End_Time: HH:MM or 4-digit e.g. 0000, 1000. See docs/CSV_FORMAT.md. Same format can be POSTed to /api/upload (multipart, field files).

商品マスターインポート LS-Central Item リスト

LS-Central の商品マスター（Itemリストエクスポート）をインポートします。アイテムNo. ↔ バーコードNo. のマッピングと商品名を登録します。インポートすると既存の商品マスターが置き換えられます。

Item Sales インポート LS-Central Item Sales レポート

LS-Central の「Item Sales」Excel レポートをインポートします。ファイルに日付が含まれないため、営業日と店舗を指定してください。インポートすると既存レポートの商品データが置き換えられます。

商品グループマスター インポート 分類マスター CSV

商品グループ（分類）マスターをCSVからインポートします。

必須列: product_group_code, description
任意列: description_tha, description_jpn, parent_code, level
階層構造: level=1 大分類 / level=2 中分類 / level=3 細分類。parent_code に親コードを指定します。
インポートすると既存データがUPSERTされます（削除はされません）。
