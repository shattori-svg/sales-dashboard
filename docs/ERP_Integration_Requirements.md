## 依頼 1：確定値の自動配信

### 送信タイミング・ルール

- 各店舗のレジ締め完了後、**全店舗分をまとめた 1 ファイル**を自動送信
- 1 日 1 回（再送信時は同日データを上書き）

### エンドポイント

```
POST https://<host>/api/upload/final
```

| 項目 | 内容 |
|---|---|
| Content-Type | `multipart/form-data` |
| 認証 | HTTP Basic 認証（別途アカウント情報を提供） |
| パラメータ | `files`: CSV ファイル |

**送信例:**

```bash
curl -X POST https://<host>/api/upload/final \
  -u "<username>:<password>" \
  -F "files=@/path/to/final_20260316.csv"
```

### CSV フォーマット（確定値）

**ヘッダー行:**

```
Business_Date,Store_Id,Department_Code,Retail_Class,Division,Net_Sales,Gross_Sales,Quantity_Sold,Receipt_Count,Discount_Amount,Item_Code,Cost_Amount
```

**列定義:**

| 列名 | 型 | 必須 | 説明 |
|---|---|---|---|
| `Business_Date` | `YYYY-MM-DD` | ◯ | 事業日 |
| `Store_Id` | 文字列 | ◯ | 店舗コード（例: `1001`） |
| `Department_Code` | `00`〜`06` | ◯ | 部門コード（下表参照） |
| `Retail_Class` | 文字列（2桁） | △ | **大分類コード**（例: `11`）。大分類行・中分類行・商品行のみ記入、他は空白 |
| `Division` | 文字列（4桁） | △ | **中分類コード**（例: `1103`）。中分類行・商品行のみ記入、他は空白 |
| `Net_Sales` | 整数 | ◯ | 純売上（値引き後） |
| `Gross_Sales` | 整数 | ◯ | 粗売上（値引き前） |
| `Quantity_Sold` | 整数 | ◯ | 販売数量（点） |
| `Receipt_Count` | 整数 | ◯ | 客数（レシート枚数）。部門行以下は `0` |
| `Discount_Amount` | 整数 | ◯ | 値引き額（正数）。値引きなしは `0` |
| `Item_Code` | 文字列 | △ | バーコード（JAN コード）。**商品行のみ記入**、他は空白 |
| `Cost_Amount` | 整数 | ◯ | 売上原価（COGS） |

> ◯=必須　△=該当行のみ記入（他は空白）

**行の種類:**

| `Department_Code` | `Retail_Class` | `Division` | `Item_Code` | 行の意味 |
|---|---|---|---|---|
| `00` | 空 | 空 | 空 | 全店舗合計日計 |
| `01`〜`06` | 空 | 空 | 空 | 部門日計 |
| `01`〜`06` | 2桁コード | 空 | 空 | 大分類日計 |
| `01`〜`06` | 2桁コード | 4桁コード | 空 | 中分類日計 |
| `01`〜`06` | 2桁コード | 4桁コード | 商品コード | 商品別日計 |

## 依頼 2：速報値への商品別データ追加

既存の速報連携（`POST /api/upload`）に、**商品別日計行の追加**をお願いします。

### 変更内容

現在の速報 CSV に `Item_Code` 列を追加し、商品別の行を含めてください。

**ヘッダー行（変更後）:**

```
Business_Date,Store_Id,Department_Code,Start_Time,End_Time,Net_Sales,Gross_Sales,Quantity_Sold,Receipt_Count,Item_Code
```

**追加する行の種類:**

| `Department_Code` | `Start_Time` | `Item_Code` | 行の意味 |
|---|---|---|---|
| `01`〜`06` | 空 | JAN コード | 商品別日計（既存の部門・時間別行に追加） |

- 商品行の `Start_Time`・`End_Time` は空白
- 既存の部門行・時間別行の形式は変更不要

**CSV サンプル（追加分のみ抜粋）:**


### 基本仕様

| 項目 | 内容 |
|---|---|
| 文字コード | UTF-8（BOM なし） |
| 改行コード | LF または CRLF |
| 区切り文字 | カンマ（`,`） |
| 複数店舗 | 1 ファイルに全店舗の行を含める |

### レスポンス

**成功 (HTTP 200):**

```json
{ "ok": true }
```

**エラー (HTTP 400 / 401 / 500):**

```json
{ "error": "エラーメッセージ" }
```

### エラー処理

| HTTP ステータス | 原因 | 推奨対処 |
|---|---|---|
| `200` | 正常受信 | 完了 |
| `400` | CSV フォーマットエラー | `error` フィールドを確認し修正して再送 |
| `401` | 認証失敗 | ダッシュボードチームに認証情報を確認 |
| `500` | サーバーエラー | 時間をおいて再送。解決しない場合はチームに報告 |
